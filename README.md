### About this repository

This repo holds the source of my portfolio site, written in plain HTML, CSS and JavaScript with no build step, and deployed with GitHub Pages.

```
index.html        page content
css/style.css     styles, light/dark themes, responsive layout
js/main.js        loader, theme toggle, scroll and pointer effects
assets/           favicon and project screenshots
```

Run it locally with `python -m http.server 5500` and open http://localhost:5500.

The "Resume" buttons stay hidden until `assets/DoanTienTrung_CV.pdf` is added.
