01 · About

A frontend developer who likes to see things through to the browser.

I recently graduated in Computer Science from Ho Chi Minh City Open University. Most of my time goes into the front end: turning screens into clean, reusable React components, making layouts hold up from a phone to a wide monitor, and wiring everything to real APIs.

I also write backend code in Java and Spring Boot, which helps me understand what the UI is talking to. When something breaks, I like following it all the way down, whether the cause is in a component, the API or the server config.

Before this, I spent four months as a software engineer intern at a fintech startup, building data scrapers and presenting results to the investment team every week.
